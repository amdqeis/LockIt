# Audit UI: pengawasan ujian, workspace bersama, dan pemilihan soal

Ruang lingkup: shared component ExamWorkspace pada tiga mode (pengerjaan, review peserta, pratinjau guru), layar persiapan fullscreen, layar hitam pemulihan, penanganan siklus pelanggaran, wizard pemilihan butir soal (manual, acak sekali per ujian, acak per peserta), dan responsivitas layout 320, 390, 768, 1440 px.

## Temuan dan mitigasi

1. **Persiapan layar penuh**
   - Layar persiapan menutup tampilan soal jika peserta masuk lewat redirect otomatis atau refresh tanpa user gesture fullscreen.
   - Tombol "Aktifkan Layar Penuh & Lanjutkan" memicu API fullscreen langsung dari interaksi klik yang valid.
   - Mode kompatibilitas aktif otomatis saat browser menolak API atau tidak mendukung, dicatat ke backend sebagai metadata pada monitoring guru.

2. **Siklus pelanggaran dan pemulihan**
   - Siklus 1 menampilkan modal peringatan yang menjeda pengerjaan hingga peserta menekan "Saya Mengerti & Lanjutkan".
   - Siklus 2 dan seterusnya atau status pemulihan wajib server (`recovery_required`) menutup viewport dengan layar hitam pekat (`exam-blackout-screen`).
   - Tombol pemulihan memvalidasi visibilitas dan fokus jendela serta mode layar penuh sebelum mengirim acknowledgment ke endpoint `/api/exam-session/recover`. Kunci pengawas tetap memiliki prioritas tertinggi.

3. **Workspace bersama (ExamWorkspace)**
   - Mode pengerjaan: interaktif dengan tombol tandai, radio/checkbox/textarea jawaban, progress bar, dan dialog konfirmasi sebelum submit.
   - Mode review: baca-saja, mempertahankan urutan soal dan pilihan peserta, menandai pilihan peserta dan kunci benar jika diperbolehkan, tanpa autosave, proctoring, atau timer aktif.
   - Mode pratinjau guru: baca-saja, menampilkan kunci jawaban, poin, dan banner informatif berlabel jelas untuk contoh penugasan N butir soal pada mode acak per peserta.

4. **Pemilihan soal pada pembuatan ujian**
   - Tahap pilih butir soal memisahkan 3 mode pemilihan: Manual, Acak sekali per ujian (dengan tombol Acak Ulang dan pratinjau hasil acak), dan Acak per peserta.
   - Pengaturan subset ini terpisah secara tegas dari checkbox pengacakan urutan butir soal dan urutan pilihan jawaban.
